# Exemple de déclencheurs négatifs

Tapez : "intro", "introduction", "introuvable" puis "introspection".
Ensuite, tapez : "connexion", "se connecter", "déconnexion", puis "se déconnecter". 

## Introduction
- intro
- introduction
- ! introuvable
- ! introspection

Ce message s'affiche si on tape "intro" ou "introduction", mais pas "introuvable" ou "introspection"


## connexion
- connexion
- se connecter
- ! se déconnecter
- ! déconnexion

ce message s'affiche si on tape "connexion" ou "se connecter", mais "déconnexion"


## déconnexion
- déconnexion
- se déconnecter
- ! se connecter
- ! connexion

ce message s'affiche si on tape "déconnexion" ou "se déconnecter", mais pas "connexion"
